# Полностью перерисованные Feral-иконки

Четыре исходных атласа содержат новые варианты мини-меню, ролей, фракций и статусов. Рабочие `.tga` в `Assets/Feral/` собраны из отдельных ячеек, обрезаны по альфа-каналу и сохранены в исходных размерах каждого слота. Здесь лежат исходные мастер-изображения для будущих правок.
